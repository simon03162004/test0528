# 團隊最高憲法 (Rule of the Orchestra)

## 核心工作週期 (Work Cycle)
所有代理人與工作流必須嚴格遵守以下四步循環：
1. **工作前先讀憲法**: 確保每一次啟動前，皆已了解本 `rule.md` 之規範。
2. **讀取紀錄**: 檢閱 `.agent/logs/` 目錄 (history.md / debug.md / functions.md) 掌握當前上下文。
3. **團隊分工協作**: 由 Orchestrator 分配任務給 PM ➔ 工程師 (唯一寫入權) ➔ 檢查員 ➔ 重度使用者。
4. **寫回紀錄**: 完成任務後，確保將狀態、決策與除錯經驗更新回 `.agent/logs/`。

## 技術棧與實作規範
- **前端原生核心技術包**: 嚴格限定使用 HTML + CSS + JS (Vanilla)，保證 Netlify 零建置秒級部署。
- **圖示資源**: 所有圖示一律使用行內高畫質 SVG (Inline SVG)，禁止引入外部圖標字體。
- **必須遵守項目**:
  - `unref` 定時器：避免定時器阻礙進程退出。
  - `EventEmitter` 解耦：模組之間必須透過事件總線或事件監聽解耦，嚴禁過度依賴。
  - `DIP` (依賴反轉) 存儲抽象：持久化存儲必須依賴抽象介面，而非具體實作。
- **敏捷開發守則**:
  - **DRY** (Don't Repeat Yourself)：避免重複代碼。
  - **SOLID**: 確保系統架構具備高擴展性與維護性。
